03 · Agent architecture

One orchestrator, two specialists working in parallel, all on the Agent Chat Protocol

If a specialist misses the 20 s timeout, the verdict uses the evidence that arrived and says so.Kavach
04 · Tech stack & flow

Built entirely on the Fetch.ai stack

uAgents 0.26 (Python)Agent Chat ProtocolAgentverse mailboxASI:One discoveryASI1 Interactive CardASI:One LLM APIuAgents BureauRDAP (rdap.org)pydantic message models

Typed messages between agents (CheckRequest → Report[Finding]). Each finding carries a weight, a category and a plain-English reason, so every verdict can be explained. Without an LLM key it still works on rules alone.

Primary flow, all inside ASI:One

  1. User pastes the message or asks "is this a scam?"
  2. ASI:One routes to kavach (Chat Protocol), which sends an acknowledgement
  3. kavach sends a CheckRequest to both specialists in parallel
  4. Specialists call tools (RDAP, regex playbooks, ASI:One LLM) and return a Report
  5. kavach merges and scores the evidence, then replies with markdown, a verdict card and EndSession

05 · Impact

A check that takes seconds, between "pay ₹1,999 now" and the student paying.

Prevents loss

Flags fee-first jobs, task scams and digital arrest scripts before money moves, the only point where recovery is cheap.

Speeds up reporting

A pre-filled complaint with the suspect's identifiers turns panic into a 1930 call or a cybercrime.gov.in filing within the first hour.

Reaches people

Lives in ASI:One with no app to install. Colleges and placement cells can share one agent link with every student.

Who it's for: students and freshers during placement season, their parents (the main digital arrest targets), and campus T&P cells checking offers that come in.
